# prev

A fast, open source document and image viewer for Linux, modelled on macOS
Preview.

- **PDF:** view, annotate, sign, fill forms, add/remove/reorder pages, redact,
  encrypt, export to images.
- **Images:** view common formats plus HEIC and camera RAW; crop, rotate,
  resize, adjust color, edit basic metadata.
- **SVG** and **Markdown** viewing.

Status: planning. See [docs/PLAN.md](docs/PLAN.md).
