File formats

DocumentsPDF, including password-protected files
ImagesPNG, JPEG, GIF and animated GIF, WebP, AVIF, HEIC and HEIF, TIFF, BMP, ICO, TGA, PNM (PBM, PGM, PPM), QOI, JPEG 2000, OpenEXR, Radiance HDR
Camera RAWDNG and the RAW formats of the cameras rawler supports, among them Canon CR2, CR3 and CRW, Nikon NEF and NRW, Sony ARW, SR2 and SRF, Fujifilm RAF, Olympus ORF, Panasonic RW2, Pentax PEF, Samsung SRW, Sigma X3F and Hasselblad 3FR
DrawingsSVG and compressed SVG (.svgz)
TextMarkdown (.md, .markdown), with tables, task lists and syntax-highlighted code
PDF exportPDF, optionally flattened, encrypted with AES-256 or with images reduced to 150 dpi; or each page as PNG, JPEG, WebP or OpenEXR, or all pages as one TIFF, at 72 to 600 dpi
Image exportPNG, JPEG, WebP, TIFF, BMP, TGA, QOI, PPM, OpenEXR; SVG and Markdown export as pictures in the same formats
MetadataEXIF, ICC color profiles and XMP kept through edits in JPEG, PNG, WebP and TIFF; keywords and descriptions saved to JPEG, PNG and WebP; location removable
Never writtenHEIC, AVIF and camera RAW open only; edits to them are exported to another format

PDF features

ViewsContinuous, single page, two pages side by side; fit page, fit width, actual size, zoom from 10% to 1,600%
NavigationPage thumbnails, table of contents, highlights and notes, bookmarks, search with every match highlighted, links, slideshow
MarkupHighlight, underline, strikethrough; sketch, draw; rectangle, rounded rectangle, oval, line, arrow, star, polygon, speech bubble, loupe, mask; text boxes and notes. Saved as standard PDF annotations
FormsText fields, checkboxes, radio buttons, drop-down menus
SignaturesDrawn, typed in a handwriting font, or imported from a photo or scan; kept in a library and placed as images
PagesReorder, rotate, delete, crop, insert blank pages or other PDFs, copy and paste between documents with their annotations and form fields
RedactionRemoves the text, image pixels and drawings under each mark and rewrites the file, so no earlier revision keeps them
SavingAutomatic, in place, with the original kept as a version; annotations saved incrementally
PrintingThe desktop's print dialog on Linux, Windows' print dialog, the macOS print panel

Languages

Interface38 languages: Arabic, Bengali, Catalan, Chinese (Simplified and Traditional), Czech, Danish, Dutch, English (US and UK), Finnish, French, German, Greek, Hebrew, Hindi, Hungarian, Indonesian, Italian, Japanese, Korean, Malay, Norwegian (Bokmål), Persian, Polish, Portuguese (Brazil and Portugal), Romanian, Russian, Spanish, Swahili, Swedish, Tamil, Thai, Turkish, Ukrainian, Urdu, Vietnamese
Right to leftArabic, Hebrew, Persian and Urdu lay out right to left inside panels, dialogs and menus
ChoosingFollows the system's language, or the one chosen in Settings
TranslationsOne Fluent file per language; the translations other than English are first drafts open to further review

Input

KeyboardShortcuts for every main action, with ⌘ on macOS and Ctrl elsewhere; changeable in the settings file, for every system or for one
TypingText fields follow the system's keyboard layout and input methods; an empty field starts on the side the input language reads from, taken from the keyboard layout on Linux, the input language on Windows and the input source on macOS
PointerMouse and touchpad: smooth scrolling, Ctrl+scroll (⌘+scroll on macOS) to zoom around the pointer, dragging to pan, select and draw
SigningMouse, touchpad, pen or touch in the signature pad
Drag and dropBoth ways on Linux (Wayland), Windows and macOS: pictures, text, files and pages in, with Ctrl (Control on macOS) sending a drop to the sidebar; text, areas, pages and images out, with Shift (or Command) to move pages
ClipboardText, images, files copied in the file manager, and pages between prev windows; wl-clipboard on Linux
AccessibilityKeyboard focus with Tab and Shift+Tab; follows the system's reduced motion setting

Technology

LanguageRust, edition 2024, Rust 1.89 or newer to build
Interfaceiced 0.14 with wgpu, and tiny-skia for drawing on the CPU
PDF engineMuPDF 1.27, through the mupdf crate
ImagesThe image crate; rawler for camera RAW; libheif with libde265 and aom's AV1 decoder for HEIC and AVIF
SVG and Markdownresvg; pulldown-cmark with syntect for highlighting
TranslationsProject Fluent
AI agentsAn MCP server, prev --mcp, on standard input and output, through rmcp; it relays to the running prev over a private local socket (a named pipe on Windows), with JSON-RPC 2.0
FontsRoboto Flex, Material Symbols Rounded and Dancing Script, bundled
System integrationXDG desktop portals on Linux; Win32 and OLE on Windows; AppKit and Launch Services on macOS, with a menu bar through muda
DependenciesAll open source, with licenses checked by cargo-deny in CI; GPL-2.0-only is refused

Performance

Measured on Linux with a release build, an RTX 4080 SUPER and a 3840 × 1080 display at 120 Hz.

MeasureTargetMeasured
Start to windowunder 150 msabout 230 ms, 200 ms of it Vulkan setup
Open a PDF to its first page drawnunder 100 ms20 ms for 499 pages, 93 ms for 7,025 pages
Scroll and zoom60 fps without dropped frames120 fps, no slow frames
Memory with one 100-page PDF openunder 150 MB61 MB heap, 179 MB resident with GPU drivers
Program sizeunder 30 MB without RAW29.9 MB, 36.1 MB with RAW

Pages render in tiles on background threads, with a 128 MB tile cache. On the CPU renderer prev scrolls at about 60 fps and zooms at about 30 fps.

License and privacy

LicenseGNU AGPL-3.0 or later, as MuPDF requires; the bundled fonts keep their own licenses (SIL Open Font License 1.1, Apache 2.0)
Sourcegithub.com/scrambletools/prev
NetworkNone of its own: prev goes online only to fetch a picture dropped onto it as a web address, and to open links you click. No accounts, no telemetry
AI agentsOnly those you allow, through prev --mcp; no bundled model. What an agent reads goes to the model it uses
Code signingWindows and macOS releases are not yet signed; see the code signing policy
